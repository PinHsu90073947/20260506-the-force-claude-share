Claude 基礎設置

Step 1 — Homebrew

Mac 上的套件管理工具，一行指令安裝各種開發工具。

$ brew install claude-code
macOS Homebrew

Step 2 — 登入啟用

安裝完成後，在終端機輸入 claude 即可啟動，首次使用會引導登入 Anthropic 帳號。

$ claude
# 首次啟動會開啟瀏覽器登入

開啟 Claude CLI

一般開啟方式

$ claude
每次執行檔案操作或指令前
都會跳出確認提示
RECOMMENDED

推薦開啟方式

$ claude --dangerously-skip-permissions
跳過所有權限確認，工作流程更順暢
僅限個人開發機使用，勿在共用環境開啟

cmux

遠端 Server 上的多窗終端管理
適合在編版機上同時跑多個 Claude

BetterAgentTerminal

本機更好的 Claude CLI 互動介面
可視化對話歷程與工具呼叫

Claude 記憶機制 Live Demo

MEMORY

記住「你是誰」

跨對話自動保留你的個人資訊與偏好。
例如：角色、技術棧、工作習慣。

~/.claude/projects/.../memory/MEMORY.md
CLAUDE.MD

記住「專案是什麼」

在專案根目錄放一份 CLAUDE.md，
每次開啟 CLI 時自動載入作為上下文。

$ claude
> /init
# 自動分析專案並產生 CLAUDE.md

兩者差異

Memory 記憶CLAUDE.md 專案說明
用途個人化偏好 & 資訊專案規則 & 上下文
範圍跨所有對話生效僅該專案目錄下生效
建立方式對話中要求 Claude 記住/init 自動產生 或 手動撰寫

翻譯助手 — 如何讓企劃使用

問題

工具只在我的電腦上、只有我會用 CLI。
克克、企劃、其他開發者要怎麼用？

解法

邊板機上已有 Discord Bot，
建一條 /translate 指令，
企劃輸入自然語言就能觸發翻譯。

Bot 不解析參數、不組指令，
只負責把企劃的話轉交給 Claude。
Claude 自己讀 CLAUDE.md 決定怎麼做。

Discord Bot 核心程式碼
spawn('claude', [ '--print', '--output-format', 'stream-json', '--verbose', '--dangerously-skip-permissions', '--model', 'sonnet', userPrompt, ], { cwd: '/path/to/Google Sheet 翻譯助手', });
stream-json — Bot 監聽輸出，
每 5 秒更新 Discord Embed 顯示進度。

翻譯助手 — 校正 AI

過程中 AI 有不理想的結果，我會告訴他問題在哪，然後讓他把反饋紀錄到 CLAUDE.md 中。
企劃使用過程中遇到問題，也用這種方式校正，持續提高準確性。

反饋 1：不該更新 Common/Dialog
「更新 001 的字串表」只更新遊戲專屬表，不連共用表一起更新。
反饋 2：摘要用詞要正確
使用者沒有要求翻譯，不該出現「翻譯流程已結束」。改用 [更新摘要] 前綴。
反饋 3：列出具體 key 名稱
不能只回報「新增 key：1 個」，要列出每個 key 名稱。
反饋 4：自動推到 Git
更新後一律自動 commit 並 push，除非明確要求 dry-run。

每次反饋都寫回 CLAUDE.md → AI 的準確性逐次提升

醞釀中的想法 探索中

自動更新多語系素材

去 NAS 抓取遊戲的多語系素材，自動套用到素材表。未來新增語系（如日文）時，不用逐一開啟專案。

自動檢查美術素材完整性

讓 AI 自動比對素材清單與實際檔案，找出遺漏或命名不一致的項目。

自動填寫遊戲企劃書

企劃克克的構想——不懂 AI 的企劃也能先行動：先寫好想自動化的內容（也就是 CLAUDE.md），其他交給 AI。

新專案自動初始化

開新遊戲專案時，讓 AI 完成基本的 Loading 介面、核心設定等。開發人員更專注在遊戲表演串接上。

有些繁瑣的事情，都可以來試著構想讓 AI 幫我們完成。

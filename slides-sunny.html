Claude 基礎設置

Step 1 — Homebrew

Mac 上的套件管理工具，一行指令安裝各種開發工具。

$ brew install claude-code
macOS Homebrew

Step 2 — 登入啟用

安裝完成後，在終端機輸入 claude 即可啟動，首次使用會引導登入 Anthropic 帳號。

$ claude
# 首次啟動會開啟瀏覽器登入

開啟 Claude CLI

一般開啟方式

$ claude
每次執行檔案操作或指令前
都會跳出確認提示
RECOMMENDED

推薦開啟方式

$ claude --dangerously-skip-permissions

Claude 記憶機制 Live Demo

MEMORY

記住「你是誰」

主動告訴 Claude 你想讓他記住什麼，
之後的對話就能沿用。

~/.claude/projects/.../memory/MEMORY.md
CLAUDE.MD

記住「專案是什麼」

執行 /init 在專案根目錄產生 CLAUDE.md，
每次開啟 CLI 時自動載入作為上下文。

💡 如果資料夾裡已有檔案，
Claude 會先分析現有內容再寫進 CLAUDE.md。

$ claude
> /init

兩者差異

Memory 記憶CLAUDE.md 專案說明
用途個人化偏好 & 資訊專案規則 & 上下文
範圍跨所有對話生效僅該專案目錄下生效
建立方式對話中要求 Claude 記住/init 自動產生 或 手動撰寫

翻譯助手 — 如何讓企劃使用

問題

現在工具只在我的電腦上，
我該怎麼讓企劃使用？

解法

邊板機上已有 Discord Bot，
建一條 /translate 指令，
企劃輸入自然語言就能觸發翻譯。

Bot 不解析參數、不組指令，
只把企劃的話轉交給 Claude。

Discord Bot 核心程式碼
spawn('claude', [ '--print', '--output-format', 'stream-json', '--verbose', '--dangerously-skip-permissions', '--model', 'sonnet', userPrompt, ], { cwd: '/path/to/Google Sheet 翻譯助手', });
stream-json — Bot 監聽輸出，每 5 秒更新 Discord 進度。
實際 DISCORD 畫面

翻譯助手 — 校正 AI

過程中 AI 有不理想的結果，我會告訴他問題在哪，然後讓他把反饋紀錄到 CLAUDE.md 中。
企劃使用過程中遇到問題，也用這種方式校正，持續提高準確性。

反饋 1：不該更新 Common/Dialog
「更新 001 的字串表」只更新遊戲專屬表，不連共用表一起更新。
反饋 2：摘要用詞要正確
使用者沒有要求翻譯，不該出現「翻譯流程已結束」。改用 [更新摘要] 前綴。
反饋 3：列出具體 key 名稱
不能只回報「新增 key：1 個」，要列出每個 key 名稱。
反饋 4：自動推到 Git
更新後一律自動 commit 並 push，除非明確要求 dry-run。
反饋 5：沿用其他表已有的翻譯
翻譯前先檢查其他遊戲表是否已翻過相同內容；若有，直接沿用，不要重新翻譯，避免同一句出現不同譯法。

每次反饋都寫回 CLAUDE.md → AI 的準確性逐次提升

翻譯助手 — 成果

遊戲發想上， 翻譯的工作就交給 AI 處理。

彩蛋 — 這份簡報怎麼做出來的？

這份簡報沒有打開過 Keynote，全程跟 Claude 對話完成。

1
先寫 CLAUDE.md

把每一頁要講什麼、放什麼資訊先用 markdown 列清楚。

2
交給 Claude 寫成 HTML 簡報

一句「幫我做個簡報」就生出可以直接開啟的 slides.html。

3
持續對話微調

色調、排版、補圖、改字、修錯——全部用聊的。

4
每補一張圖 → Claude 自動找位置放

我只要丟圖檔，AI 會判斷該放哪一頁、用什麼排版。
